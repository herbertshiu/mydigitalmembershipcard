1. **https://zo.computer** — sign in
2. Connect GitHub (`kristychannn` needs **Write** on this repo)

4. **Automations** → **+** → daily 8:30 AM HKT
5. Paste instruction from `ZO_PROMPTS.md`
6. **Run now** to test
